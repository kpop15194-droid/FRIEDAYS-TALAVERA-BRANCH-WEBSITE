# Friedays – Talavera Branch Website

A creative, responsive website for Friedays Talavera Branch.

## Website Features

- Responsive desktop and mobile design
- Friedays-inspired orange, cream, and black theme
- Complete menu with prices
- Menu categories and search function
- Chicken flavor selection
- Shopping cart
- Quantity controls
- Automatic estimated total
- Pre-order form
- Pickup date and time fields
- Facebook Messenger handoff

## How to Publish with GitHub Pages

1. Open your GitHub repository.
2. Click Settings.
3. Select Pages from the left sidebar.
4. Under Build and deployment, choose Deploy from a branch.
5. Select the main branch.
6. Select the / (root) folder.
7. Click Save.
8. Wait for GitHub Pages to publish the website.

## Important Order Information

This website prepares an order message and opens the configured Facebook link.

It does not automatically:
- Save incoming orders to a database.
- Notify staff about new orders.
- Check live product availability.
- Reserve pickup slots.
- Confirm orders automatically.

Customers must send their order request through Messenger and wait for confirmation from Friedays staff.
